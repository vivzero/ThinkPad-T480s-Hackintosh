| Parts | Details |
| - | - |
| CPU | Core i7-8650U |
| GPU | UHD Graphics 620 |
| RAM | 2 * 8 GB DDR4-2400T |

## Issues
* Brightness hotkeys don't work.
* HDMI doesn't work.
* Hibernation (mode 25) causes kernel panic.
